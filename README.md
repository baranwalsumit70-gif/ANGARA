# Angara Product Page Redesign

Desktop and mobile product detail page (PDP) redesign prototypes.

- `index.html`: desktop (1280px)
- `mobile.html`: mobile (390px)

Both files are self-contained, with fonts, scripts and all product images embedded. No build step is needed.

## Publish with GitHub Pages
1. Create a new repository and upload all three files.
2. Go to Settings → Pages → Source: `main` branch, `/ (root)`.
3. The site goes live at `https://<username>.github.io/<repo>/`, with mobile at `/mobile.html`.
